Измерение структуры

Шаг 1 — калибровка: см по шкале аппарата
Статус калибровки: не задана
Шаг 2 — измерение:
Калибровка: нажмите «Указать отрезок», проведите линию точно вдоль отметок шкалы аппарата (например, между делениями 1 см), впишите реальную длину — программа запомнит масштаб. Затем «Провести линию измерения» по нужной структуре — получите её размер.
Устанавливаем защищённое соединение…
Наденьте наушники, чтобы не было эха. Микрофон включите, если хотите говорить с врачом.
Бета-прототип. Соединение P2P, шифруется WebRTC. Публичный сигналинг PeerJS используется только для установления связи.
Измерение по видеокадру — ориентировочное, зависит от точности калибровки по экранной шкале. Для клинически точных измерений используйте DICOM-инструменты аппарата.
Не для клинического применения без обезличивания данных и юридического оформления.
